# Near-miss registry

Hazards inside our control, append only. Kept by the Steward. Checked by E11.

A near-miss is a hazard we can design away: the countermeasure is a redesign that ships as
a check. A limitation we cannot design away goes in `docs/known-issues-registry.md`.

Copy `docs/templates/registry-entry.md` for each new entry. IDs run RG-001, RG-002 and so
on, ascending without gaps. Anticipatory entries, hazards caught before any failure, are
as welcome as reactive ones.
