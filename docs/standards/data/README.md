# Data standards

Placeholder for the data discipline, planned for v0.2. Data standards are artifacts of
type `standard` and live in this folder.

v0.2 will cover:

- **Schema change policy:** versioning, backward compatibility, expand-then-contract migrations.
- **Data contracts beyond APIs:** events, files and tables passed between components.
- **Data quality:** validity, completeness and provenance of real data.
- **Reference and seed data:** who owns it and how it changes.
- **Governance:** access, deletion, lineage and audit.
- **When a dedicated Data Architect seat is warranted:** the trigger for a crew review.

Until then, the Architect seat owns the data layer (floor row D2), the Operator owns the
classification rule (C5), and the Verifier owns the test data standard (D10).
